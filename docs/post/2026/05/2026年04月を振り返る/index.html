2026年04月を振り返る

2026/05/07· yjuba

02月03月は後追いになってしまいましたが、04月はなんとかなりそうです。今日はGWの中日で平日かつ出社日でした。やや疲弊していますが、GW明けのリハビリとしては良い日だったと思います。

04月にやりたかったこと

健康診断を乗り切る

昨年と違う病院という事を前々日に知りました。家からは近いので徒歩で向かいましたが、オフィスビルの1フロアをぶち抜いている事に気づかず入るのに苦労しました。

結果は昨年同様微妙でしたが、鎮静剤の効きが良かったため胃カメラのダメージが少なく済みました。トータルでは良かったと思います。

05月にやりたいこと

減量

少なくとも、04月の平均体重は下回りたい。

7.5絶の準備

一番大切なメンバー集めは終わっているので、自分自身の体調や体力作りをしたいと思います。

Fitbitの新調

長らくSense 2を使っていますが、バッテリーが持たなくなってきたので新調を検討しています。これを書いている最中、ふとググったら噂されていたFitbit Airの情報が公開されていました。書き終わったら検討します。

仕事

直近は残業時間がかさんでいます。先月から続いてるRADIUS絡みの案件で想定された範囲を超えて関与しているので致し方ない部分はあるのですが。とにかく、絶までに落ち着かせたいので走れるうちに頑張って走っています。大枠として私が果たすべき責務の部分は大分落ち着いてきたので、この調子であれば何とかなるでしょう。

本業の認証・認可周りは大きな動きは無く、粛々と溜まっている課題を片付ける日々が続いています。

最近使用しているエージェント・モデル

過去を遡れると面白そうなので書いておきます。前提として、業務で明らかに影響があったのはOpus 4がリリースされた後のClaude Codeでした。そこからは暫くClaude Code一本で、GPT 5.4がでたあたりからレビュー用としてCodexも使用しています。Copilot CLIは触ったのみです。他のツールは触れたことがありません。

04月の利用状況は以下の通りでした。

  • Codex
    • モデル: GPT 5.5
    • 用途: highでプランの作成、lowでプランの実装
  • Claude Code
    • モデル: Opus 4.7
    • 用途: Codexが作成したプランと実装のレビュー

03月くらいまでは逆だったのですが、以下の理由から04月は役割が入れ替わりました。

  • ClaudeのAPIが色んな意味で不安定
  • GPT 5.5の登場でGPTのレスポンスが早くなったこと
    • 逆にClaudeは不安定かつ遅くなっている
    • 特にGPT 5.5 lowが早くて不満が少ない

趣味

FF14

7.5の実装、絶の内容確定、8.0拡張の発表と色々ありました。7.5が来るまではモグコレついでにFLを走り、7.5実装後のGWは極のトーテム99個を目指して走りきりました。とりあえず、絶まではぼちぼちやっていくだけになりそうです。

買った物

ドーロライトパンツはユニクロのチノパンが傷んできたので、普段着の代わりに買いました。動きやすくカジュアル過ぎないので気に入っています。除湿機は一時期湿度が酷かったので買いましたが、気温が上がってきたので暫く出番は無さそうです。

Wave XLR Mk.2はAG03の代替機として購入しました。マイクのゲインが大分増えたので、Discordの音量調整をOFFで運用できるのは助かっています。割とBridgeCastと悩みましたが、AI曰く私の用途ならこっちと言われたので一旦こっちを購入しました。絶を通して使ってみて様子を見てみるつもりです。

  • THE NORTH FACE ドーロライトパンツ
  • CORONA 除湿機 CD-P63A3(W)
  • Elgato Wave XLR MK.2

終わりに

とりあえず04月分は何とか通常通り書けたので安心しています。05月分も絶が始まるまでに書けば大丈夫でしょう。
