2026年08月を振り返る

2026/09/06· yjuba

おそらく今年に入って初めてしっかりと体調を崩しました。水曜日の夕方から怪しく、木金と殆ど寝ていましたが下痢以外の症状が無く困っていたところ、土曜日の朝に喉と鼻に痛みを覚えて耳鼻科に行きました。インフル・コロナが流行り始めているということで検査をしましたが陰性だったため、とりあえず薬を貰って今は殆ど回復しています。分かりやすい症状があれば合わせた病院へ行くのですが、中々これと言った症状が無かったので苦労しました。

08月にやりたかったこと

（先月書き忘れていたらしい）

Pixel、Fitbitの新調

例年通り8月に Pixel 11 が発売されたので、 Pixel 11 Pro XL に乗り換えました。 NFC の位置が変わって戸惑った以外は特に大きな違いを感じていません。モデムが変わったおかげか、若干通信が安定したのと、バッテリーの持ちが良い気がします。

256GB モデルでメモリが減らされていること、なぜか Pixel 10 シリーズの下取りの金額がおかしいことに気づいて、翌日に再注文して回避しました。やる気ある人ほど予約開始と同時に買うと思うので、こういうのは辞めてほしいですね。

Fitbit はいよいよ限界だったので、始めて Pixel Watch に手を出して5を買いました。 Fitbit よりは重い、電池持ちは流石に悪いという点はありますが、思ったより視認性が良いので現状は気に入っています。

09月にやりたいこと

引き付き減量

体調を崩したことで滅茶苦茶になっているので頑張ります。

個人開発の着手

FF14 も凪節に入り、仕事もおそらく9月で落ち着くはずなので前々から着手したかった物に着手しようと思っています。雑に Codex を契約して実装しようと思っていましたが、折角なので OpenCode Go でやってみようと思います。

仕事

2023年から取り組んでいる SSO の案件ですが、9月末で無事に節目を迎えることができそうです。3年以上に渡るプロジェクトは今の会社に入ってから初めてですが、とりあえず終わりが見えてきたので一安心といった状態です。引き続き、同じプロジェクトで改善やより広い範囲への関与が求められそうなので、頑張っていきます。

また、仕事兼個人用に始めて Agent Skills を整備しましたが、思っているよりは効果があったので、めんどくさがらずにもう少し整備しようと思いました。

趣味

FF14

7.5絶固定のメンバーに確認したところ、皆さん継続いただけるということで、早くも8.0零式のメンバーが確定して安心しています。（暫く期間が空くので、後日改めて最終確認を取りますが、大きく変動は無いだろうと思っています。）

完全なる凪節に入ったので、フロントラインルーレットを回す以外は、所持品・リテイナーの整理や潜水艦のルートの調整をしながら過ごしています。今回は、ジョブメカニズムが大きく替わる事もあり、他ジョブを触ることも無さそうです。

買った物

例年通り Pixel を更新した以外は特に大きな買い物は無かった様子です。近い将来欲しい物に大物が多いので、しっかり現金を準備しようと思います。

  • Pixel 11 Pro XL
  • Pixel Watch 5

近い将来欲しい物（？）

  • DELL XPS 13: 個人用のノートPCとして欲しい、DHH氏がべた褒めしていたのも気になる
  • 新しい EIZO の 4K ディスプレイ: 今使っている EV3285 がやや調子が悪い。現状未発売で情報も無いけど、7年保証を打ち出したのでそろそろ出るのでは？と勝手に期待している。
  • 新しい DGX Spark: こちらもいつ出るのか不明ですが、新世代が出たら狙ってみたいと思っています。
  • 新しいデスクトップPC: サブ機は Win11 が動かず、メイン機も2021年発売の Alder Lake でそろそろ限界が近い。 Nova Lake にはとても期待しています。

本当は、 WiFi 7 対応の YAMAHA の AP も欲しかったけど、ディスプレイを新調すると USB-C 経由で有線が渡せるので優先度が下がってしまいました。

終わりに

そろそろ査定の時期なので文章を書くことが増えています。これを乗り切ったら、忘れる前に年末恒例の講義用の資料も仕上げて身軽になりたいところですね。

これを書いている今、台風の影響でまたしても関東近辺で浸水被害が出そうな話が耳に入りました。流石に自宅周辺は大丈夫だと思うのですが、大事にならずに済むと良いなと思っています。
